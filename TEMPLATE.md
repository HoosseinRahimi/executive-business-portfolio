# Template customization checklist

1. Edit `assets/config.js` for name and contact links.
2. Replace the hero headline and introduction.
3. Add a verified professional biography in About.
4. Replace generic business interests with actual sectors.
5. Add only real company and brand affiliations.
6. Add markets with a short explanation of the activity in each market.
7. Turn Projects / Deals entries into concise case studies.
8. Publish useful business analysis in Insights.
9. Define clear partnership criteria.
10. Update colors in `assets/styles.css` and add brand assets if needed.
